# Support

AFDH is an Apache-2.0 kernel. There is no paid support line in 0.1.

| Need | Where |
| --- | --- |
| How a gate works | [docs/README.md](docs/README.md) |
| Land a scanner / mux / SVID | [docs/ADAPTERS.md](docs/ADAPTERS.md), then an issue labelled `adapter` |
| A gate that should have blocked, did not | Issue template **Fail-closed bug** |
| Working exploit | [SECURITY.md](SECURITY.md) — private advisory, not a public issue |
| Conduct | [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

Please search [open issues](https://github.com/trendy2472024-collab/afdh/issues) before opening a new one. Good first issues are labelled `good first issue`.
