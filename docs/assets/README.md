# Brand

Palette matches the control-plane chrome. Do not introduce a second language.

| Token | Hex | Use |
| --- | --- | --- |
| bg | `#0b0d10` | Field |
| surface | `#12151a` | Panels |
| fg | `#e8e6de` | Primary type |
| muted | `#8d939c` | Secondary type |
| accent | `#a8b4c4` | Marks, frames |
| ok | `#86c4a4` | Allow, pin, core |
| fail | `#d07c7c` | Deny — a deny is a pass |

Type: monospace (DejaVu Sans Mono / JetBrains Mono). No purple. No gradient blobs.
